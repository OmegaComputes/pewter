# @omegacompute/pewter

Pewter CLI: orchestration for GPU compute, from the terminal. Installs two commands, `pewter` and `pew` (identical).

    npm i -g @omegacompute/pewter
    pewter login
    pewter --help

The binary comes from a per-platform optional dependency. Nothing is downloaded at install time.
